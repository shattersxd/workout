# Workout Routine

Трекер тренировок для зала. PWA, один HTML-файл, работает офлайн, ставится на
домашний экран iPhone.

**Открыть:** https://shattersxd.github.io/workout

## Что умеет

- Пресеты Push / Pull / Legs и Full Body A / B / C на 3 дня
- Конструктор своих дней из пула ~210 упражнений с заменами по группам мышц
- Редактирование пресетов и добавление упражнений **во время** тренировки
- Расписание по дням недели, нужный день открывается сам
- Разминка под каждый день с пошаговыми подсказками
- Таймер отдыха, который перезапускается с каждым закрытым подходом и выживает
  после блокировки экрана
- Журнал: история тренировок, прогрессия по каждому упражнению, сравнение с
  прошлой неделей, корзина для случайно удалённых записей
- Достижения: стрики и количество тренировок
- Вес гантелей можно считать за одну гантель или за пару

## Разработка

```bash
python3 scripts/build.py      # src/ -> index.html
node tests/test_pwa.js        # 221 тест, должно быть 221/221
```

Или одной командой:

```bash
make            # собрать и проверить
make check      # проверить, что index.html не отстал от src/
```

Править нужно `src/workout_tracker.jsx`. `index.html` — результат сборки.

## Структура

```
src/workout_tracker.jsx   приложение целиком: данные + компонент App
src/shell/head.html       <head>, CSS, лоадер, PWA-манифест, бутстрап Babel
src/shell/tail.html       ErrorBoundary и монтирование React
scripts/build.py          сборка одного файла
tests/test_pwa.js         регрессионный набор
index.html                собранное приложение, его раздаёт GitHub Pages
CLAUDE.md                 ограничения платформы и контракты данных
```

Перед изменениями стоит прочитать `CLAUDE.md` — там собраны причины, по которым
код написан именно так: Babel на iOS падает на не-ASCII символах в строках,
optional chaining не транспилируется, пропущенная запятая в объекте валит всё
приложение. Каждое такое падение закрыто тестом.
