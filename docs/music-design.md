# Музыка в приложении: варианты и планы

Статус: **решено пока делать только Spotify** (пульт и мини-плеер в тестовой версии). Остальное
записано здесь как план. Вернуться к нему имеет смысл после проверки Spotify на телефоне.

## 1. Что хотим

Чтобы музыкой можно было пользоваться и без подписки (бесплатно), и с подпиской, если она уже есть
у человека на каком-то сервисе, а управление было прямо из приложения тренировок.

## 2. Главное ограничение iPhone

Приложение, добавленное на экран «Домой», **останавливает звук при сворачивании или блокировке
телефона**, а продолжить воспроизведение с экрана блокировки часто нельзя
([форум Apple](https://developer.apple.com/forums/thread/762582),
[разбор разработчиков](https://dev.to/prototyp/what-we-learned-about-pwas-and-audio-playback-50eh)).
Из-за этого интеграции делятся на два типа:

| Тип | Как работает | Переживает блокировку и другие приложения | Кому подходит |
|---|---|---|---|
| **Пульт** | Играет приложение сервиса, мы управляем через его API (так сделано со Spotify) | да | подписчикам; у Spotify управление требует Premium |
| **Плеер внутри приложения** | Звук воспроизводится нашей страницей | нет, только пока приложение открыто | зависит от сервиса |

Для тренировки плеер внутри приложения приемлем: экран у нас не гаснет (Wake Lock). Нельзя будет
переключиться в другое приложение, не остановив музыку.

## 3. Сервисы

| Сервис | Бесплатно | С подпиской | Тип | Примечания |
|---|---|---|---|---|
| **Spotify** | нет | да (Premium) | пульт | сделано. Встроенный плеер Spotify (embed) на мобильном даёт только 30-секундные превью ([форум Spotify](https://community.spotify.com/t5/Spotify-for-Developers/Embed-code-full-songs-vs-preview/td-p/5514126)), бесплатному пользователю не помогает |
| **Apple Music** | нет | да | внутри приложения (MusicKit JS) | нужна ваша платная программа Apple Developer (около $100 в год) для токена разработчика ([описание](https://dev.to/areknawo/apple-music-javascript-integration-guide-518b)); у слушателя нужна подписка. Пульта к приложению Apple Music у веба нет |
| **Jamendo** | да, полные треки | не нужна | внутри приложения | бесплатная легальная музыка независимых исполнителей (Creative Commons); бесплатный ключ для некоммерческих проектов ([описание API](https://publicapi.dev/jamendo-api)); у каждого трека своя лицензия, её надо читать из ответа API |
| **Интернет-радио** | да | не нужна | внутри приложения | тысячи станций, аккаунт не нужен; проще всего |
| **Свои файлы** | да | не нужна | внутри приложения | аудио из «Файлов» телефона |
| **YouTube** | с рекламой | - | внутри приложения | по моим сведениям, условия сервиса не разрешают звук отдельно от видео и в фоне; не рекомендуется |
| **Яндекс Музыка, VK Музыка** | - | - | - | по моим сведениям, официального API для таких приложений нет; обходные пути нарушают условия и ломаются; не рекомендуется |

Проверить перед началом работы с любым сервисом: актуальные условия и лимиты на его сайте. Они меняются
(у Spotify режим разработки менялся в феврале 2026).

## 4. Как это устроить: «источник музыки»

Мини-плеер на главной уже один для всех вкладок. Источников может быть несколько, пользователь выбирает
в настройках: **Spotify (если есть Premium)**, **бесплатный** (радио и Jamendo) или **Apple Music**
(если есть подписка). Без подписки музыка всё равно доступна.

Для этого нужен общий интерфейс провайдера. Он уже угадывается в модуле Spotify:

| Метод | Что делает | В коде Spotify сейчас |
|---|---|---|
| `connect()` / `disconnect()` | вход и выход | `spStartLogin`, выход в панели |
| `nowPlaying()` | что играет, на паузе ли | `spFeedRefresh`, `SPOTIFY_FEED.view` |
| `play()` / `pause()` / `next()` / `previous()` | управление | `spCommand` |
| `search(q)` / `lists()` | выбор музыки | `spSearchPath`, `SPOTIFY_PLAYLISTS_PATH` |
| `playItem(kind, id)` | запуск выбранного | `spPlayBody` |
| `capabilities` | что умеет источник (пульт или внутри, нужна ли подписка) | пока неявно |

Когда появится второй источник, общую часть (подписка на состояние, очередь запросов, мини-плеер, выбор)
нужно вынести из `spotify.jsx` в нейтральный слой, а Spotify оставить одной из реализаций. Делать это
заранее смысла нет: интерфейс уточнится по второму сервису.

## 5. Что надо проверить на телефоне до выбора

1. **Spotify** (цепочка): вход, запуск музыки в приложении Spotify, пауза и «Дальше» из мини-плеера,
   выбор плейлиста, поиск трека. Это главное, на чём стоит всё остальное.
2. **Звук внутри приложения при включённом экране.** Простой тест на коротком файле или радио: играет ли
   звук стабильно, пока приложение на экране, и что происходит при блокировке. Результат определит, годится ли
   вообще вариант «внутри приложения» для iPhone.

## 6. Рекомендуемый порядок

| Шаг | Что | Результат |
|---|---|---|
| 0 | Spotify: пульт, мини-плеер, выбор музыки (сделано в тестовой версии) | Работает у подписчиков Premium |
| 1 | Проверка на телефоне (раздел 5) | Решение, какие источники оправданы |
| 2 | Бесплатный источник: радио и Jamendo | Музыка для тех, у кого нет подписки |
| 3 | Общий интерфейс провайдера и выбор источника в настройках | Несколько источников в одном мини-плеере |
| 4 | Apple Music для подписчиков (нужна программа Apple Developer) | Подписка Apple Music внутри приложения |
