# Ачивки и праздник при получении

> Перенесено из `CLAUDE.md`. Читать при работе с `ACHIEVEMENTS`, `achStats`, `achPlan`, `AchCelebration`.

- **Ачивки** (`ACHIEVEMENTS`, 37 штук в разделах `ACH_GROUPS`: постоянство, сила и объём,
  дисциплина, секретные). У каждой `id`, `group`, `icon`, `name`, `desc`, `type`, `req`;
  получена, когда показатель `achStats(data, today)[type] >= req` (булевы показатели - 0 или
  1). `achStats` - чистая функция по журналу (тесты исполняют её на синтетических журналах):
  объём (сумма весов отмеченных подходов), максимальный вес, личные рекорды (вес выше всех
  прежних; первое выполнение упражнения рекордом не считается), разные упражнения,
  идеальные тренировки и цепочка, тренировок за неделю, охват в днях, полные недели PPL.
  **Серия недель для ачивок - лучшая подряд (`weeks`)**, а для карточки СТРИК -
  текущая (`curStreak`): неполная текущая неделя серию не обрывает.
  Журнал режется до `HISTORY_LIMIT` записей на день, показатели - «по сохранившимся».
  **Секретные** (`secret: true`) в списке: пунктирная рамка, «?», «???» и общий текст, пока не
  получены (название, описание и значок выводятся только через маскирующие выражения,
  тест это проверяет). Время суток (ночная смена, ранняя пташка) берётся только у записей
  `src: "manual"`: у остальных `ts` может быть полуночью. Новую ачивку добавляйте с новым
  `id`; `ACH_LEGACY` (старые двенадцать) и их условия менять нельзя. Иконки - эмодзи из
  U+1F000 без селекторов вариации и склейки.
- **Праздник при получении ачивки.** `data.achSeen` - карта «id -> дата праздника» (`""` -
  получена ещё до праздников). Эффект в `App` считает `achPlan(data)`: **первый запуск после
  обновления** (карты нет) молча запоминает старые двенадцать, а новые, что уже выполнены,
  празднует; больше `ACH_BATCH_MAX` (4) новых за раз (загрузка копии) - не праздник, а тост
  «Новых ачивок: N»; остальное идёт в очередь `achQueue` с паузой 0.9 с, чтобы успел
  показаться тост «Тренировка сохранена!». Окно `AchCelebration` (z-index 700, выше меню):
  карточка, всплеск значка с кольцами, 22 конфетти (положение по номеру, без `Math.random`:
  перерисовка ничего не двигает); у секретной сначала «?», он переворачивается и открывает
  значок. Закрытие записывает `achSeen[id]`, повторов нет. `achSeen` у каждого устройства
  свой, `mergeBackup` его не берёт. Ключевые кадры (`ach*`, `menu*`) лежат в `head.html`,
  каждый движущийся элемент помечен `className="app-anim"`, а правило
  `prefers-reduced-motion` отключает анимации; «естественный» вид окна итоговый (слои
  украшений невидимы сами по себе), поэтому без анимации всё читается.
