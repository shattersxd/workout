# Тестовая версия: удобства тренировки

> Перенесено из `CLAUDE.md`. Читать при работе с `src/beta/ux.jsx` (звук, рекорд, итог, календарь) и при переносе его в основную версию.

**Удобства тренировки** (`src/beta/ux.jsx`, секция 27 тестов; пока только в бете, по просьбе заказчика
сначала проверяются там, на боевую страницу не попали). Четыре вещи:
1. **Звук в конце отдыха и при рекорде** (Web Audio, `uxPlay`). Вибрация из Safari на iPhone не работает,
   `new Notification` из свёрнутой страницы не доходит, а экран во время тренировки не гаснет, поэтому
   слышимый сигнал - единственный, который доходит. Контекст создаётся и «будится» в обработчике
   нажатия подхода (`uxOnSetDone`, iOS пускает звук только после жеста). Настройка - блок «ЗВУК» в
   «Настройки» (`UxSettings`, кнопка «ПРОВЕРИТЬ ЗВУК»), хранится **отдельным ключом** `sila_sound_beta`
   (в основной версии будет `sila_sound`), не в `data`. **Не проверено на телефоне:** боковой
   переключатель «без звука» на iPhone глушит Web Audio, в PWA с домашнего экрана контекст может
   засыпать при блокировке экрана. Не обещать звук при свёрнутом приложении.
2. **Рекорд во время тренировки** (`uxRecordCheck`): вес выше всех ПРОШЛЫХ отмеченных подходов
   упражнения (журнал минус дополняемая запись и сегодняшнее автосохранение этого же дня), выше
   других подходов этой тренировки и выше уже отпразднованного (`uxCelebrated`). Первое выполнение
   упражнения рекордом не считается (как в ачивках). Всплывашка `UxRecordPop` сверху, 4.2 с.
3. **Итог после сохранения** (`uxSummary`, `UxSummary`): время, объём (`formatVolume`), подходы,
   упражнения, % к прошлой такой же тренировке, рекорды, номер тренировки на неделе. Заменяет тост
   «Тренировка сохранена!» (`uxOnFinish` возвращает `true`, иначе тост остаётся). Праздник ачивки
   ждёт, пока итог открыт. Время: первый отмеченный подход пишет `data.started[ключ сессии]`,
   при сохранении в запись попадает `dur` (минуты, дольше 240 - не показываем; у дополняемой записи
   остаётся прежнее). `started` чистится в `pruneOldKeys`.
4. **Календарь в журнале** (`uxCalMonth`, `UxCalendar`, `UxDaySheet`): третья вкладка «КАЛЕНДАРЬ»,
   месяц с понедельника, точки цветом тренировки, итоги месяца, окно дня с «ОТКРЫТЬ В ЖУРНАЛЕ»
   (переключает на журнал, сбрасывает фильтры и прокручивает к записи по `id="jr-<ts>"`).

Устройство: чистые функции лежат выше разделителя «Интерфейс» в файле и исполняются тестами как есть
(`todayKey`, `APP_VARIANT`, `localStorage`, `window` тест подставляет; **в шапке файла нельзя
повторять строку-разделитель целиком**: тест режет файл по первому её вхождению), компоненты - ниже.
В боевом коде только **швы**, и каждый защищён `typeof ux... === "function"` (тест секции 27 проверяет
каждое упоминание): `uxRestDone` в тике таймера, `uxOnSetDone` в `toggleDone`, `uxEntryExtra` и
`uxOnFinish` в `finishWorkout`, `UxSettings`, `UxCalendar` + вкладка журнала, `uxRestDoneClass` у
карточки отдыха, `UxLayer` (стили анимаций, всплывашка, итог). Ключевые кадры `ux*` лежат внутри
модуля (`UX_CSS`), а не в `head.html`: боевая страница пока не меняется. Каждый движущийся элемент
помечен `app-anim` (тест), «естественный» вид окон итоговый, цвета - токены темы, тексты без «ты» и
«вы» (экраны тренировки и журнала в основной версии на «ты», тест следит за обращениями).
