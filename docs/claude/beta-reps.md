# Тестовая версия: фактические повторы

> Читать при работе с `src/beta/reps.jsx`, строкой подхода, карточкой отдыха, записью журнала (`detail`), подсказкой
> прогрессии и при переносе модуля в основную версию.

**Фактические повторы** (`src/beta/reps.jsx`, секция 31 тестов; пока только в бете). Раньше в подходе хранился только
вес, повторы были диапазоном из программы («8-10»).

## Как это работает

- **Во время отдыха.** После отметки подхода в карточке отдыха (`FxTimer`, свойство `extra`) появляется ряд из шести чисел
  (`RxAsk`, `rxChips`: диапазон программы и соседи) и «...». Одно нажатие записывает повторы только что отмеченного
  подхода; строка над рядом подтверждает («Подход 2: записано 8 повт.»). Отдыхать всё равно надо, поэтому лишнего шага
  в тренировке нет. «...» открывает окно со всеми числами.
- **В строке подхода** вместо текста «8-10 повт.» стоит кнопка (`RxChip`, на всю высоту поля, 44pt): показывает
  записанное число или диапазон программы; нажатие открывает окно выбора (`RxSheet`: числа 1..20 и дальше, диапазон
  программы обведён, «УБРАТЬ ЗАПИСЬ»). Записать можно и заранее, до отметки подхода.
- **Ничего не выдумывается.** Не выбрал число - повторы остаются неизвестными, запись журнала выглядит как раньше.
  Значения по умолчанию нет намеренно: подставленное число выглядело бы как факт.
- **Упражнения на время** («30 сек», `rxPlan` возвращает `null`): повторов нет, строка подхода прежняя, карточка
  отдыха не спрашивает.

## Где видны записанные повторы

- журнал: подход подписан «95x8» (`rxLabel`);
- свёрнутая выполненная карточка: «4 x 95 кг | 8, 8, 8, 7 повт.» (`rxList`; неизвестное - «?»);
- **совет перед упражнением** (`rxPast` + `rxAdvice`, `RxTip`), двойная прогрессия: если в прошлый раз во ВСЕХ подходах
  взят верх диапазона - «пора прибавлять вес» (и работает прежняя подсказка «+2.5» с кнопкой «ВЗЯТЬ»); если нет -
  «Сначала 10 во всех подходах, потом прибавка веса», а подсказка «+2.5» **не показывается**. Совет даётся, только
  если повторы записаны у всех выполненных подходов прошлого раза; иначе всё как раньше.

## Данные

- сессия: `sessions[ключ][id упражнения][номер подхода].reps` - целое 1..200 (`rxSetReps`; мусор не записывается);
- запись журнала: поле `r` у подхода в `detail` (`rxDetail`), обратно при «Дополнить» - `rxRestore`;
- подходы без повторов пишутся в прежнем виде `{ w, done }`: основная версия читает такие записи как раньше, а записи
  с `r` для неё безвредны (лишнее поле игнорируется). Объём и прежняя прогрессия по-прежнему считаются по весам.
- «Прошлый раз» для совета - последняя по дате запись дня с этим упражнением, без сегодняшней и без дополняемой.

## Швы в основном коде (все под `typeof`)

`rxPlan` в `toggleDone` (пятый аргумент - диапазон из программы; ставит `rxAsk`), сброс `rxAsk`, когда карточка отдыха
закрылась; `RxChip` в строке подхода; `rxDetail` в `finishWorkout` и в автосохранении; `rxRestore` в `resumeSession`;
`rxLabel` в журнале; `rxList` у свёрнутой карточки; `rxAdvice`/`rxPast`/`RxTip` перед подсказкой прогрессии; `RxAsk`
внутри `FxTimer`; `RxSheet`; `RX_ASK_H` (`rxLift`: отступ страницы и плашка отмены поднимаются на высоту ряда чисел).
Состояние в `App`: `rxAsk` (о каком подходе спрашивает карточка отдыха), `rxPick` (для какого открыто окно).

## Не сделано и не проверено

- **На iPhone не проверено.**
- Ряд чисел живёт в новой карточке отдыха (`src/beta/focus.jsx`); без неё повторы записываются только кнопкой в строке.
- Объём («тонны») по-прежнему сумма весов без повторов; рекорды и ачивки повторы не учитывают.
- Расчёта 1ПМ и графиков по повторам нет.
- Повторы слева/справа («10-12 на сторону») записываются одним числом.

## Перенос в основную версию

`git mv src/beta/reps.jsx src/features/reps.jsx`. Ряд чисел требует карточки отдыха из `focus.jsx` (её свойство `extra`),
поэтому переносить после неё или вместе с ней. Тексты нейтральные, цвета - токены темы и цвет дня.
